Tauri + Rust React SQLite Local-first Offline Windows

Genel Bakış

Saatlerce debug yaptıktan sonra hâlâ "bir commit daha" demek tanıdık geliyor mu? Cooldown, yazılımcıların çalışma anındaki stres sinyallerini — derleme hataları, terminal çöküşleri, context switch'ler, yazma temposu — sessizce izler ve bunları 0–100 arası bir Fatigue Score'a dönüştürür.

VS Code, Cursor, PowerShell ve Zsh ile entegre çalışır; verilerinizi buluta göndermeden yerel SQLite veritabanında saklar. Tauri mimarisi sayesinde arka planda çalışır, sistem tray'inde yaşar ve ihtiyaç duyduğunuzda mola hatırlatır.

Sonuç: Daha sürdürülebilir kodlama ritmi, daha bilinçli molalar, daha az sessiz tükenmişlik.

Nasıl Çalışır?

01

IDE & Terminal Hook'ları — VS Code / Cursor eklentisi build, lint ve test hatalarını; PowerShell & Zsh hook'ları başarısız komutları 127.0.0.1:9876 adresine sessizce iletir.

02

Rust Backend Analizi — Pencere geçişleri, klavye temposu ve hata olayları birleştirilerek anlık Fatigue Score hesaplanır. OS seviyesinde event-driven pencere takibi minimum CPU/RAM kullanır.

03

Yerel SQLite Depolama — Metrikler, journal kayıtları ve kişisel baseline güvenle cihazınızda saklanır. Bulut yok, telemetri yok, üçüncü taraf API yok.

04

React Dashboard — Cognitive Map, Screen Time, trend raporları ve akıllı mola bildirimleri tek arayüzde. System tray ikonu anlık durumu renkle gösterir.

Öne Çıkan Özellikler

⚡

Gerçek Zamanlı Fatigue Score

Context switch, hata yoğunluğu ve yazma temposundan dinamik 0–100 skor. Anlık güncelleme, 2 sn gecikme yok.

🔌

IDE & Terminal Entegrasyonu

VS Code, Cursor, PowerShell ve Zsh hook'ları ile build/compile hataları ve failed command'lar otomatik yakalanır.

🔒

Tamamen Yerel (Local-first)

Veriler yalnızca cihazınızda. Hassas pencere filtreleme, retention policy ve şifre/banka pencerelerinde otomatik koruma.

☕

Akıllı Mola Hatırlatıcıları

Kademeli uyarılar (60/75/90), smart snooze, bağlama göre mola önerileri ve micro-journal ile molaları anlamlı kıl.

🧠

Cognitive Map & Deep Work

Günlük bilişsel yük grafiği, derin odak skoru, haftalık/aylık trendler ve kişisel baseline karşılaştırması.

📊

Screen Time Analizi

IDE, tarayıcı ve iletişim uygulamaları arasında geçirilen süreyi kategorize eder — nereye gitti odaklan?

🎯

Focus Mode

25/50 dakikalık odak seansları; kritik olmayan bildirimleri susturur, yalnızca gerçek burnout sinyallerinde uyarır.

🖥️

Tray + Mini Widget

Renkli tray ikonu (yeşil/sarı/kırmızı), sürüklenebilir mini widget, arka planda sessiz çalışma.

Geliştirici Dostu Detaylar

  • Hata türü ayrıştırma: build, lint, test, runtime, terminal
  • Anomali tespiti & proaktif mola önerileri (14 günlük baseline)
  • Plugin registry — vscode, terminal, powershell kaynak takibi
  • Micro-journal arşivi: "Molaya çıkmadan ne üzerinde çalışıyordum?"
  • Benchmark modu: bellek, CPU ve uptime self-monitoring (~80–130 MB RAM)
  • Karanlık / yumuşak aydınlık tema, veri retention policy (30–365 gün)
  • Windows ekran kilidi algılama ile gerçek mola süresi ölçümü

Neden Cooldown?

Çünkü sürdürülebilir kodlama, yalnızca hızlı commit'lerden ibaret değil — bedeninizin ve zihninizin sinyallerini dinlemekten geçiyor. Cooldown, yazılımcıların en savunmasız olduğu anda — saatlerce süren debug loop'larında, ardışık CI hatalarında, "bir tab daha" deyip kaybolunan akşamlarda — yanınızda sessiz bir co-pilot gibi durur.

Daha az burnout. Daha bilinçli molalar. Daha iyi kod.
