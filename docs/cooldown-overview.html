Overview

Ever found yourself saying "one more commit" after hours of debugging? Cooldown quietly watches stress signals while you work — build errors, failed terminal commands, context switches, typing cadence — and turns them into a Fatigue Score from 0 to 100.

It integrates with VS Code, Cursor, PowerShell, and Zsh, storing everything locally in SQLite — never in the cloud. Built on Tauri, it runs in the background, lives in your system tray, and nudges you to take breaks when you need them.

The result: a more sustainable coding rhythm, more intentional breaks, and less silent burnout.

How It Works

01

IDE & Terminal Hooks — The VS Code / Cursor extension sends build, lint, and test errors; PowerShell and Zsh hooks report failed commands silently to 127.0.0.1:9876.

02

Rust Backend Analysis — Window switches, keyboard tempo, and error events are combined into a live Fatigue Score. OS-level, event-driven window tracking keeps CPU and RAM usage minimal.

03

Local SQLite Storage — Metrics, journal entries, and your personal baseline stay on your device. No cloud, no telemetry, no third-party APIs.

04

React Dashboard — Cognitive Map, Screen Time, trend reports, and smart break notifications in one interface. The tray icon shows your status with color.

Developer-friendly Details

  • Micro-journal archive: "What was I working on before this break?"
  • Benchmark mode: self-monitoring for memory, CPU, and uptime (~80–130 MB RAM)
